# AI Career Pulse — Decoding the AI Job Market

## Project Overview
AI Career Pulse is an interactive data analytics project that explores the AI job market using Tableau and Flask.

## Objectives
- Analyze AI job postings across different roles and industries
- Compare salaries across job roles and experience levels
- Analyze job demand by category
- Explore remote-work opportunities
- Compare job postings across countries and years

## Dataset
The project uses the `ai_jobs_market_2025_2026.csv` dataset containing 1,500 AI job records.

## Tools & Technologies
- Tableau Public
- Python
- Flask
- HTML/CSS
- GitHub

## Tableau Visualizations
The project includes visualizations for:
- Jobs by Role
- Jobs by Experience Level
- Average Salary by Role
- Salary by Experience
- Jobs by Industry
- Remote Work Distribution
- Job Demand by Category
- Jobs by Country
- Jobs by Year
- Remote-Friendly Jobs

## Tableau Public
https://public.tableau.com/app/profile/sathwik.surineni/viz/AI_Career_Pulse/Dashboard1

## Flask Web Integration
The Tableau dashboard is embedded into a Flask web application using an HTML iframe.
